hlw installer

Harness Launch Wrapper — one-liner install for macOS and Linux.

Install

curl -fsSL https://hlw.first-it-consulting.com/install.sh | bash

Dry run (verify without installing)

curl -fsSL https://hlw.first-it-consulting.com/install.sh | bash --dry-run

Flags

  • --dry-run: resolve version + platform, download and verify the checksum, but don't install.
  • --prefix=DIR: install to a specific directory (default: ~/.local/bin). Requires write access.
  • --version=VER: pin a specific version (default: latest release tag).

What it does

  1. Detects your platform (darwin/linux, arm64/amd64).
  2. Fetches the latest release tag from GitHub.
  3. Downloads the platform tarball and verifies its SHA-256 against the release's checksums.
  4. Copies the binary to your chosen prefix (or a writable temp dir if you lack permissions).
